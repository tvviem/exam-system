# Nhãn hiệu BLUni

`bluni-wordmark.svg`: chữ "BLUni" (nhãn hiệu của Trường Đại học Bạc Liêu), lấy nguyên đường nét từ `plo-tracker-bluni/frontend/public/favi-bluni.svg`; chỉ bỏ kích thước cố định theo cm để co giãn bằng CSS. **Không đổi màu, không biến dạng.**

Quy ước dùng (chủ dự án chọn, 11/11/2026): **chỉ một chỗ** là chân trang đăng nhập, đặt trên thẻ trắng. Không dùng ở thanh bên, favicon hay biểu tượng PWA (đó là biểu tượng riêng của hệ thống). Viết tên đúng nhãn hiệu: **BLUni** (chữ hoa BLU, chữ thường ni).
